# StudyQuest

## Introduction

StudyQuest is an AI-powered learning companion app that turns studying into an adventure. Built at HackLondon 2026, it combines a gacha-style companion collection system with genuine AI-driven lessons — because learning is more fun when you have a team rooting for you.

Collect companions, build your island base, and send your party on expeditions. The more you study, the stronger your companions grow. Complete AI-generated lessons to earn resources, upgrade your buildings, evolve your companions from commonto legendary, and take on increasingly tough bosses in turn-based combat.

## Features

- AI Lessons — Topic-based lessons generated by Claude with interactive Q&A
- Gacha Collection — Pull companions of varying rarity, each with unique abilities
- Island Base — Upgrade your Town Hall, Hospital, Blacksmith, and Lab
- Expeditions — Send companions out to earn XP and materials while you focus on studying
- Turn-Based Combat — ATB combat system with mana, abilities, and status effects
- Companion Progression — Level up, evolve rarity, and equip your party

## How to run

1. Clone this repository

```
git clone https://github.com/Ryanli-BP/Study-Quest.git
cd Study-Quest
```

2. Install required dependencies

```bash
cd frontend
pip install -r requirements.txt
cd ../backend
flutter pub get
```

3. Run frontend

```
cd frontend
flutter run
```

4. Run backend

```
cd backend
uvicorn app.main:app --reload --port 8000
```
